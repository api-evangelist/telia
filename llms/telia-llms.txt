# Telia Company

> Nordic and Baltic telecommunications group (Solna, Sweden) running mobile and fixed
> networks in Sweden, Finland, Norway, Denmark, Lithuania, Latvia and Estonia, plus a
> global carrier and IoT business. Telia runs a first-party developer hub at
> developer.teliacompany.io fronting two programmes — LSO Sonata (MEF/Mplify and TM
> Forum wholesale ordering) and CAMARA (GSMA Open Gateway network APIs) — but both
> catalogs sit on Apigee portals gated behind an existing commercial agreement, a
> whitelisted corporate email domain and manual approval. Exactly ONE OpenAPI
> definition is downloadable anonymously across the whole estate.

## What is actually callable

- [LSO Sonata Geographic Site Management API](https://lso.teliacompany.com/apis): the only Telia OpenAPI available anonymously. MEF 122 / MEF 79, TM Forum TMF674 lineage. Two GET operations, OAuth 2.0 client credentials, production/test/sandbox hosts.
- [Bulk Messaging SMS REST API v2](https://cdn.messaging.teliacompany.com/documents/developer/index.html): POST ~/messages and POST ~/content at https://api.messaging.teliacompany.com/sms/rest/v2, HTTP Basic. Fully documented in a public implementation guide; its OpenAPI is portal-gated.
- [Bulk Messaging SMPP API](https://cdn.messaging.teliacompany.com/documents/developer/index.html): SMPP 3.4 over TLS at smpp.messaging.teliacompany.com:3550, static source-IP ACL required.
- [Telia ACE Audio Stream Forwarding API](https://github.com/telia-oss/ace-audio-stream-forwarding-api): proto3 bidirectional gRPC streaming, mutual TLS. Telia publishes the proto, a sender simulator and an example receiver openly.
- [Telia ACE Knowledge REST API](https://github.com/telia-oss/ace-knowledge-docs): tenant-subdomain REST on {subdomain}.humany.net — matching, notices, contact and webhook surfaces, documented openly on GitHub.
- [Telia Tunnistus identification broker](https://tunnistus.telia.fi/.well-known/openid-configuration): OIDC/OAuth 2.0 identity provider for Finnish strong electronic identification, issuer https://tunnistus.telia.fi/uas. Discovery is anonymous. No CIBA endpoint.

## What is named but NOT reachable

- CAMARA Quality on Demand, CAMARA Device Location, NGMLC Location — named on
  https://camara.teliacompany.com/ ; the anonymous API catalog returns zero documents.
- LSO Sonata Geographic Address (TMF673), Product Offering Qualification (TMF679),
  Quote (TMF648), Order (TMF622) and Notification APIs — specifications behind sign-in.
- Telia Finland Catalogue Service, Mobile Subscription and Mobile Subscription Order
  Service APIs — anonymous catalog returns zero documents.
- Telia ACE Web API, Agent API, Workitem API, Screen Pop API, Interaction View API —
  described on https://ace-showcase.com/products/ace-apis-and-integrations/ with no
  public specification.

## Onboarding reality

Not self-serve. Access to the LSO Sonata and CAMARA catalogs requires an existing Telia
commercial agreement, a whitelisted corporate email domain, manual approval of the
account and a second approval of the registered app. The Telia Developer's Toolbox
terms add that fees are per-API and require a separate agreement per API. Bulk
Messaging requires a signed agreement per Telia country. SMPP additionally requires
static source IPs whitelisted in Telia's ACL. For network APIs specifically, Telia's
public route to developers runs through Nokia's Network as Code aggregator platform
rather than directly.
